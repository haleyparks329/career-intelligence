# Philosophy

Career Intelligence starts from the premise that career reasoning should be accurate before it is persuasive.

## Model The Person

Most resume tools compare a document to a job description. This framework tries to model more of the person:

- evidence-backed accomplishments
- transferable skills
- working style
- values and motivation
- caveats and weak signals
- role fit and role risk

The point is not to create a more flattering story. The point is to make the story more honest and useful.

## Keep Claims Grounded

The framework treats claims as things that need provenance. A claim can be strong, weak, reflective, conflicting, or unsafe for a given use.

That distinction matters. A useful interview-prep insight is not automatically a resume claim. A reflection can help someone understand fit without becoming a credential.

## Preserve Gaps

Gaps are part of the output. A good match report should show what is supported, what is adjacent, and what is not evidenced.

The system should not hide missing evidence by rewriting adjacent experience as direct experience.

## Separate Reasoning From Generation

Reasoning can be expansive. Generation should be narrower.

The public demo follows that boundary by allowing the person model to influence match, positioning, and prep while keeping resume output tied to source-backed bullets and accomplishments.
