# `make demo`

Run the synthetic Andy Barks demo.

```bash
make demo
```

## Inputs

- `examples/andy-barks/data.yaml`
- public schema-compatible engine code

## Outputs

```text
examples/andy-barks/generated/
```

Files:

- `match_report.md`
- `resume.md`
- `interview_prep.md`
- `positioning.md`
- `visualization.svg`
- `demo_data.json`

## Safety Notes

The demo is synthetic. It should not require private data, network access, or private repository access.
